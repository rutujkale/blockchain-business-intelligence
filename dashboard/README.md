# Power BI (secondary artifact)

The primary deliverable for this project is the **web app** in
[`../webapp`](../webapp) — a Next.js 16 application with seven analytical
pages. This folder holds the optional Power BI build.

The `.pbix` file is **not committed** (see `.gitignore`) and is not required to
run, reproduce, or deploy anything here.

## What is in this folder

| Path | Committed | Purpose |
|---|---|---|
| `build_spec.md` | yes | Page-by-page model spec: relationships, measures, page layout. |
| `dax_measures.md` | yes | DAX measure definitions and the KPI formulas behind them. |
| `data_extracts/*.csv` | yes, except `fact_transactions.csv` | The five tables Power BI imports. Also the **input** to `src/analysis/export_for_webapp.py`, which generates the web app's static JSON. |
| `blockchain_bi_dashboard.pbix` | no (gitignored) | The built report. Rebuilt locally. |

`data_extracts/` is load-bearing for the web app — do not delete it. It is
regenerated by `src/analysis/export_for_dashboard.py`.

## Rebuilding the .pbix locally

1. Install Power BI Desktop.
2. Run the pipeline through step 5 in the root [`README.md`](../README.md).
3. Open `data_extracts/` and import the five CSVs, or follow
   [`build_spec.md`](build_spec.md), which documents the relationships and
   measure wiring in the order the model expects.
4. Add the measures from [`dax_measures.md`](dax_measures.md).
5. Save as `blockchain_bi_dashboard.pbix` in this folder.

## Why it was demoted

The Power BI report is desktop-only, cannot be linked or shared as a URL, and
required a licensed authoring tool to change. The web app covers the same
analysis with the same numbers, adds a wallet-level explorer, responsive
layouts, and CSV export, and deploys as a static site. The Power BI build is
retained as a secondary path for stakeholders who prefer a desktop report.
